# QUALITY ASSURANCE (QA) – KHOLIK RENT CAR

## 1. Deskripsi Proyek
Repositori ini merupakan dokumentasi kegiatan Quality Assurance (QA) terhadap website **Kholik Rent Car** (https://kholikrentcar.com/). Pengujian dilakukan untuk mengevaluasi kualitas website berdasarkan standar ISO/IEC 25010 dengan panduan ISO/IEC 25002:2024.

Kegiatan ini dilaksanakan secara berkelompok sebagai bagian dari tugas perkuliahan dengan tujuan mengidentifikasi kesesuaian fungsi, menemukan kemungkinan kesalahan (defect), serta mendokumentasikan hasil pengujian secara sistematis.

## 2. Tujuan Pengujian
- Memastikan seluruh fitur website berjalan sesuai dengan fungsi yang diharapkan.
- Mengidentifikasi kesalahan atau bug pada fitur website.
- Mengevaluasi kualitas dan perilaku website dari sisi pengguna.
- Mendokumentasikan proses dan bukti pengujian.
- Menyediakan rekomendasi perbaikan berdasarkan hasil pengujian.

## 3. Metodologi Pengujian

Pengujian menggunakan dua pendekatan utama:

### A. Black Box Testing
Pengujian dilakukan dengan memeriksa seluruh fitur website dari sisi pengguna tanpa melihat kode program internal. Pengujian mencakup navigasi, tombol, informasi layanan, katalog kendaraan, tautan, dan fitur lain yang tersedia.

### B. White Box Testing
Pengujian dilakukan dengan memeriksa struktur internal, logika, dan kode program untuk mengetahui kesesuaian implementasi sistem. Pelaksanaannya menunggu informasi dan arahan lanjutan dari pihak mitra pada minggu kedua sesuai kesepakatan awal.

## 4. Standar Pengujian
- **ISO/IEC 25010:2023** – Product Quality Model.
- **ISO/IEC 25002:2024** – Quality Model Overview and Usage.
